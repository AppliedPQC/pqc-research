# Figures for bitcoin-l2-pq-migration.md

One directory per post; these belong to `bitcoin-l2-pq-migration.md` in the repository root.

Each figure is committed twice: the `.svg` is the editable source, and the `.png` is what
the document references, since raw SVG does not render reliably from a raw URL on GitHub
or through the blog build.

| Figure | Shows |
|---|---|
| `roadmap` | Figure 1: the surfaces of Table 1 in migration order against the four NIST CSWP 39 stages, coloured by the party that gates each row |

To change one, edit the `.svg` and re-export the `.png` at twice the display size, which is
what keeps the labels sharp when the image is scaled down to the prose column.

The cells of the roadmap are the cells of Table 2 in the post, shortened; a change to the
table should be carried into the figure.
